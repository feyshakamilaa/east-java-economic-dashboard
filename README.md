# Dashboard Ekonomi Jawa Timur

### Analisis dan Visualisasi Data Ekonomi Regional

Dashboard interaktif berbasis web yang dikembangkan sebagai prototipe akademik untuk menampilkan dan menganalisis perkembangan indikator ekonomi di Provinsi Jawa Timur.

Proyek ini mengimplementasikan kompetensi Sains Data dalam pengolahan data, analisis statistik, analisis deret waktu, serta visualisasi informasi melalui antarmuka yang interaktif dan mudah dipahami.

## Fitur Utama

- **Ringkasan Ekonomi** — Gambaran umum indikator perekonomian Jawa Timur.
- **Inflasi dan Harga Pangan** — Analisis perkembangan inflasi dan harga komoditas pangan.
- **Ekonomi Daerah** — Perbandingan indikator ekonomi kabupaten dan kota di Jawa Timur.
- **Eksplorasi Data** — Penelusuran dan penyajian data melalui tabel interaktif.

## Teknologi

- Python
- Pandas & NumPy
- HTML, CSS & JavaScript
- Chart.js

## Tentang Proyek

Proyek ini dikembangkan sebagai portofolio akademik sekaligus prototipe pendukung pengajuan Kerja Praktik di Kantor Perwakilan Bank Indonesia Provinsi Jawa Timur.

Seluruh data yang digunakan merupakan data simulasi untuk keperluan pembelajaran dan pengembangan kompetensi Sains Data.

## Disclaimer

Dashboard ini merupakan proyek akademik independen dan tidak merepresentasikan data, kebijakan, maupun sistem resmi Bank Indonesia atau Badan Pusat Statistik (BPS).
